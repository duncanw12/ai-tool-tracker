Why these two

  • HOL Guard fills the gap between the scanners we already list and a full sandbox. Snyk Agent Scan and SkillSpector check skills and MCP servers before you install them, and Strands Box wraps an agent in OS-level isolation but only on Apple silicon Macs for now. HOL Guard sits inside the agents you already run (Claude Code, Codex, Cursor, Copilot CLI, Gemini CLI and more) and checks each action at the moment the agent tries it: a destructive shell command, a read of your .env file, a package install, an MCP tool call. Your policy decides whether it is allowed, blocked or sent to you for approval, and every decision is kept in a local history. It is open source (Apache-2.0), needs no account, has about 1,000 GitHub stars and roughly 76,000 PyPI downloads in the past month, and shipped v3.58.0 yesterday. Caveat: it can only see what each agent's hooks expose, so treat it as one layer, not a guarantee.
  • Zendesk joins the IT service desks we list next to Freshservice, Jira Service Management and ServiceNow. On Oct 26 it announced employee service AI agents and advanced action flows: an employee asks in Slack, Teams or the help center, and the agent can run onboarding and offboarding steps, access approvals, laptop lifecycle tasks and badge requests, with admins writing the automations in plain language. Zendesk says 300 early-access customers ran 6 million workflow executions in five weeks (its own figure). General availability rolls out Nov 3 to Dec 1, 2026; from Nov 3, Growth and Professional plans include 10 automated resolutions per AI agent per month and extra ones cost $0.99 each. If you are applying to help desk jobs, Zendesk is one of the ticketing systems you are most likely to see in postings, and its 14-day free trial is enough to learn the ticket workflow.

Listing updates

Checked on Oct 28, 2026 against official pages and announcements.

  • Cursor: the Cursor Agent SDK (announced Oct 20, general availability in v0.3.0 on Oct 23) lets you build your own agents as code: prompts in Markdown, tools as TypeScript functions, evals and event replay built in, and a local playground. Deploy with agent-sdk deploy to Cursor's infrastructure, or self-host it as a single Node process in a container. Agents can respond to pull request events from GitHub, GitLab or Bitbucket, and Cursor says it is the same framework behind its own Bugbot and Security Review. Cursor also added DeepSeek V4.1 Flash on Oct 26: an open-weight model with a 1M-token context and five reasoning levels (no image input). It counts as a third-party model, so it is billed from prepaid credit rather than included usage. Cursor's claim that it is the cheapest per task on its own CursorBench is the vendor's benchmark, not an independent test.
  • Lovable: the Oct 20 changelog also added an n8n connector (list workflows, read executions and trigger webhooks on your own n8n instance), a LlamaParse connector for parsing documents into structured data, and ByteDance's Seedream 5 Pro (image generation and editing with up to 10 reference images) and Seedance 2.5 (4-30 second videos with synced sound) for app features, once a workspace admin enables ByteDance in Connectors. Gemini 2.5 chat models were retired for app AI features on Oct 22.

Category changes
