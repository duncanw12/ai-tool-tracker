Why these four

  • Jira Service Management is one of the ticketing tools you'll see most in help desk job posts. The free plan covers up to 3 agents with no time limit, so you can build a small service desk with a request portal, queues, SLAs and a knowledge base, then walk an interviewer through it. Rovo AI agents come with the paid Standard plan.
  • Mantis is Google's open-source (Apache-2.0) set of skills that lets AI coding agents find, reproduce and patch vulnerabilities, with a reference harness you can point at a repo and tell what to hunt for in plain English. It has about 2,500 GitHub stars. Google's own README says to run it only in isolated environments and to verify every finding by hand before reporting it, so try it on a deliberately vulnerable practice app in a VM.
  • Fish Audio released Drama 3 on Oct 13: a text-to-speech model you direct in plain language (a whisper stays a whisper, a laugh lands where you put it) that also handles multi-character scenes. The weights are open and free for commercial use if your revenue is under $500,000 a year, but self-hosting needs a 48GB NVIDIA GPU. The hosted app has a free plan, and Plus is $11 a month billed annually. Fish Audio says the API is 80% off and new creator plans are 50% off until Nov 12.
  • Harness2 from Google Cloud AI Research improves the system around an agent (prompts, tools, memory, skills) rather than the model, and keeps what worked for the next task. It runs OpenCode or Codex as the executor and passed about 13,500 GitHub stars in two weeks. It's research code, not an official Google product, so it's for tinkerers for now.

Checked on Oct 20, 2026 against official pages and announcements.

  • Cursor is now sold as part of The X Subscription. Plus is $8 a month with Grok models only; Premium, at $30, adds cloud agents, automations and third-party models such as Claude and GPT, which are billed separately at API list price. If you're weighing the switch, see our Cursor alternatives page.
  • Devin: Cognition says Fusion, which pairs Claude Opus 5.5 as the lead with GPT-6 Luna as a cheaper sidekick, scores 68.1 on the Artificial Analysis Coding Agent Index at 31% lower cost per task than Claude Code with Opus 5.5. The cost figure is Cognition's own. Fusion is in Devin Desktop and the Devin CLI.
  • ElevenLabs added Instant Soundtracks on Oct 15: upload a video and get an original score with sound effects timed to what's on screen.

Update: OpenCode Console breach

Since our Oct 19 note, Anthropic has revoked Claude API keys it believes were affected, Google has blocked exposed Gemini keys, and OpenAI says it has refunded API credits used in the attack. OpenCode says it has contacted every affected user and its own refunds are underway, and its follow-up email lists each exposed key and puts the earliest possible exposure at 8:30 PM ET on Oct 16. If you got the email, replace those keys (a Claude key that suddenly fails was likely revoked), check usage back to Oct 16 and set spend limits. Keys added locally in the OpenCode CLI or desktop app weren't affected. The OpenCode listing is updated.
