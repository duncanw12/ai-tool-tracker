Why this one

  • Firecrawl was on GitHub Trending again this morning and has about 204,700 GitHub stars. Most agents need web pages in a form a model can read, and Firecrawl does that job: scrape a page or crawl a whole site into clean markdown, search the web, and pull from 550+ data providers through its Alexandria service, through an API, SDKs, an MCP server or a command-line tool. You can use the hosted cloud (the free plan has 1,000 credits a month), run Firecrawl Local as a single binary on your own machine, or self-host the full server; the code is AGPL-3.0, so read the license before building a product on the self-hosted version. For IT and security learners it is a handy way to feed vendor docs, advisories or a runbook site to an agent without copying and pasting.

Listing updates

Checked on Nov 20, 2026 against official release notes.

  • OpenAI Codex: Codex CLI 0.171.0 (Nov 19, a stable release) adds GPT-6.2 Sol and Astra to the model catalogs with Sol as the default selection, turns the terminal workspace on by default (searchable document previews, image previews and subagent transcripts beside the main conversation), adds codex exec --remote to start or resume non-interactive sessions on an existing app server, adds /rc and /remote for remote control with device pairing codes, and fixes enterprise MCP sign-in for identity providers that issue ID tokens without refresh tokens.
  • Claude Code: v2.1.329 (Nov 19) adds a trust-dialog warning that says where a folder's hooks are declared, a warning when hooks in managed settings fail to load, and scheduled tasks, /loop wakeups and forks in /tasks. It fixes ~/.claude.json sometimes being reset to defaults after a network stall or file lock, repeated sign-outs on macOS when the Keychain could be read but not written, and /terminal-setup corrupting VS Code settings files.
