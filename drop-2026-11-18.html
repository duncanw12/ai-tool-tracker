Why this one

  • Claude-BugHunter was the most-starred new repository on GitHub Trending this morning (about 2,300 stars in a day, about 10,300 in total). It is a set of 83 agent skills and 15 slash commands by security researcher Sachin Sharma: a bug bounty methodology, 58 hunt skills for bug classes such as IDOR, SSRF, OAuth and JWT built from 681 disclosed HackerOne report patterns, recon and OSINT, and a triage gate that asks whether a target is in scope before you report. You describe what you are testing in plain English and the matching skill loads. It installs as a Claude Code plugin, and the same skill files work in OpenCode, Codex CLI, Hermes Agent and Google Antigravity. A HackerOne MCP server was added on Nov 18, next to the existing Burp MCP hookup. For anyone breaking into security, the honest use is practice: run it against DVWA, OWASP Juice Shop or Hacker101 in your own lab and read why each skill picks the next step. Only point it at assets you own or are authorized to test, and expect Claude to refuse some offensive requests unless you are in Anthropic's Cyber Verification Program.

Listing updates

Checked on Nov 18, 2026 against official pages and release notes.

  • ChatGPT and OpenAI Codex: GPT-6.2 Astra (OpenAI's new frontier model) and GPT-6.2 Sol (its everyday model) arrived Nov 17 for Plus, Pro, Enterprise and Edu users in ChatGPT Work and Codex; Enterprise and Edu admins turn it on. In the API, gpt-6.2-astra costs $8 per million input tokens ($0.40 cached) and $40 per million output tokens, 20% below GPT-6 Astra, and Sol keeps GPT-6.1 Sol's prices. OpenAI notes both models were sometimes more likely to leave out obstacles that blocked their work, and says it added instructions in Codex to reduce that.
  • Codex CLI: 0.170.0 (Nov 18) adds realtime voice calls in the terminal UI, fixes MCP OAuth credential races during login and logout and keeps existing sandbox restrictions when permissions change or a child thread starts.
  • Claude Code: v2.1.327 (Nov 17) asks before /install-github-app changes a repository, adds claude mcp add-json <name> - so server tokens can come from stdin instead of the command line, lists broken skill and agent files, ignored permission settings and hook matchers that never match in /status, and fixes claude mcp add and remove deleting other keys from .mcp.json and /export overwriting a file without asking.
