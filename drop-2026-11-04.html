Why these two

  • AI-Infra-Guard (A.I.G) puts five AI security scanners behind one web UI. It fingerprints AI services such as model servers and agent tools on a host and matches known vulnerabilities, scans MCP server code, audits agent skills, sends test prompts to a running agent and runs jailbreak evaluations against any OpenAI-compatible model. It comes from Tencent's Zhuque Lab, is free under Apache-2.0, has about 7,400 GitHub stars and ships a release almost every week (v4.6.8 on Oct 29 split each scanner into its own pip package). We already list single-purpose scanners like SkillSpector, Snyk Agent Scan and garak; A.I.G is the one place to run all of those checks. It has no login, so keep it on a lab network, and only scan systems you own or are allowed to test.
  • CISO Assistant is a different side of security: governance, risk and compliance. It tracks risk assessments, audits and vendor reviews against 200+ frameworks, including ISO 27001, NIST CSF, SOC 2, CIS Controls, PCI DSS and HIPAA, and maps controls between frameworks so one piece of evidence counts toward several. An optional AI chat mode (off by default) answers questions about your own risks and controls using a local model through Ollama or LM Studio. The Community edition is free to self-host under AGPLv3; Pro SaaS starts at €39 per contributor per month, billed annually. About 4,600 GitHub stars and v4.2.0 on Nov 1. For anyone eyeing GRC analyst roles, a self-run assessment of your home lab is a portfolio piece hiring managers can follow.

Listing updates

Checked on Nov 4, 2026 against official pages and release notes.

  • AiSOC: v22.0.0 (Nov 4) fixes seven security advisories in its approval and authorization code: two critical, four high and one medium. One critical bug let an approver with no tenant approve another tenant's actions; the other accepted unsigned Slack and Teams approval replies. Three fixes refuse calls that used to work (API keys can no longer enroll sign-in factors, tenant admins lose the deployment-wide tenant pages, and viewers can no longer run playbooks), so read the release notes before you upgrade. If you run AiSOC in a home lab, update now.
  • Security Onion: 3.4.0 (Nov 2) adds Agentic AI Automations for Security Onion Pro users and updates Suricata to 8.0.8, Zeek to 8.0.11 and Elasticsearch to 9.4.8. The core platform stays free; Onion AI and the new automations are Pro features. Security Onion 2.4 reached end of life on Oct 1, 2026.
