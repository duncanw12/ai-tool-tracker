Why these two

  • PyRIT (Python Risk Identification Tool) is the open-source, MIT-licensed toolkit Microsoft's AI Red Team uses to probe generative AI systems. It runs automated scans and adaptive multi-turn attacks, such as jailbreak and prompt-injection attempts, against a model or AI app, scores which ones got through, and includes CoPyRIT, a web UI. It has about 4,700 GitHub stars, gets commits almost every day, hit v1.0 in July and shipped v1.1.0 on Sep 4. We already list NVIDIA's garak and promptfoo; PyRIT is the one to learn if your work runs on Azure and Microsoft AI. Only point it at systems you own or are authorized to test.
  • Factory Droid is a coding agent from Factory that works with whichever model you pick, in a desktop app for macOS and Windows, a terminal UI and an SDK. Droid 1.0 (Oct 29) turns on Script mode by default for supported models: instead of calling tools one at a time, the model writes a short JavaScript program, run in a sandbox, that makes many tool calls in a single request, so raw files and logs stay out of its context. Factory says that cut cost 15% on Claude Opus 5.5 and that Droid beat other harnesses in its own benchmark runs; those are Factory's numbers. Plans start at $20/mo.

Listing updates

Checked on Nov 2, 2026 against official pages and announcements.

  • ChatGPT: account switching is rolling out in the iOS and Android apps (release notes, Oct 30). You can stay signed in to up to two accounts and switch in Settings > Switch account. Chats, memory, files and subscriptions stay separate, which helps if you keep a work and a personal account. It also works on the web.
  • OpenAI Codex: GPT-6.1 Terra, OpenAI's fast, cheaper model for computer use and writing, is available in Codex and ChatGPT Work for Plus, Pro, Enterprise and Edu users (released Oct 26). OpenAI says your plan's allowance covers more tasks with Terra than with GPT-6.1 Sol or GPT-6 Astra. API price: $1 per million input tokens and $5 per million output.
