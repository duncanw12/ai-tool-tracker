Why these two

  • Mistral Large 4 is the biggest open-weight model so far pitched directly at security teams. Mistral released the weights on Oct 29 (about 1T parameters, 49B active, 1M-token context) and says it is built for defensive work: reproducing and patching vulnerabilities, malware analysis and writing detection rules, while refusing clearly malicious requests. Mistral reports 51% on the Artificial Analysis Cyber Index and a 96.6% refusal rate on malicious cyber prompts; those are Mistral's numbers, not our tests. Why it matters for defenders: you can run it inside your own network, so source code and incident data never leave it. It is not a home-lab model, though. Self-hosting needs data-center GPUs; most readers should try it through the Mistral API ($0.70 per million input tokens, $2.10 per million output) or OpenRouter. The license is a modified MIT that is free for most uses, but companies selling it as a hosted model service need a commercial license.
  • Radar is for anyone heading into DevOps, cloud or platform support. It is a single open-source binary (Apache-2.0) that shows a live Kubernetes cluster as a topology graph, event timeline, Helm and GitOps view and a 44-check audit, with no account and no cluster data sent out. Its built-in MCP server hands Claude Code, Codex, Cursor or Copilot a trimmed, secret-redacted view of the cluster instead of raw kubectl output; diagnosis is read-only by default, write actions follow your Kubernetes RBAC, and --mcp-read-only locks it down further. It has about 4,000 GitHub stars, shipped v1.19.0 on Oct 29 and made the Product Hunt top 10 that day. Radar Cloud is optional: free for up to three clusters, then from $149 per cluster per month.

Listing updates

Checked on Oct 30, 2026 against official pages and announcements.

  • Gemini: since Oct 29 you can generate, preview and edit files right in a Gemini chat. Expand a file to full screen to type edits, or highlight a section and ask Gemini to change it. PDFs work on the web and mobile; Google Docs, Sheets, slide decks, Markdown, TXT and code are web only for now. Google says it is available to all Gemini users, with no admin control in Workspace.
  • ElevenLabs: SFX v3 (Oct 29) is its newest sound effects model. It handles prompts that describe several sounds at once more reliably, does better with music and vocals, and is less likely to add harsh artifacts to sounds like gongs, chimes and whistles. It is in ElevenCreative and the ElevenLabs API now.

Category changes

  • AI for IT & Cybersecurity grows from 41 to 43 tools. The Breaking into IT guide adds Radar (break a deployment in a home-lab Kubernetes cluster and troubleshoot it with and without an AI agent) and a note that big security models like Mistral Large 4 are API-only for home labs.

Checked, not listed

  • Gemini 4 Carbon (Google, announced Oct 28): Google calls it its strongest model for cybersecurity, but for now only a subset of cyber defenders can use it, so we'll cover it when developers and regular users can try it.
  • Adversa AI Coding Agent Security Platform (Oct 29): endpoint security for coding agents, but sales-led with no self-serve tier.
  • Safe AI Coding (an MIT-licensed Claude Code security skill, Oct 29) and safeagents (an Apache-2.0 proxy that screens agent tool calls, Oct 28): promising, but brand new with little traction yet, and they overlap HOL Guard, which we already list.
  • Product Hunt Oct 29 (Empacer, Scape, Floot in ChatGPT, Gologin Cloud Browser): real launches, but small-business assistants, email and app builders sit outside today's IT focus.
