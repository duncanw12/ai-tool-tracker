Why these three

  • Recursive Flint is Recursive's first model: 39.8B parameters in total but only about 2.5B active per token, so it runs fast on local hardware. Recursive reports 125+ tokens a second on an M4 Pro MacBook Pro and says it leads mixture-of-experts models under 50B parameters on SWE-Bench Pro v2, Terminal-Bench 2.1 and SWE-Bench Verified (vendor benchmarks). The weights are Apache-2.0 on Hugging Face and it's already in Ollama as flint:40b. Hardware reality: the official INT4 GGUF needs a 48GB Apple Silicon Mac, and Unsloth's 3-bit GGUF fits 24GB of RAM at short contexts. Recursive itself says to break complex work into smaller steps.
  • OpenAI Decisions API went GA on Oct 22. Instead of generating text, it answers a question you define with a probability, one of your allowed choices, or a score, from text, images or JSON. It runs on GPT-6 Luna, costs $0.10 per million input tokens ($0.01 cached) with no output-token charges, and OpenAI says it's up to 10x faster than asking Luna through the Responses API. Good fit for routing, triage, guardrails and agent "should I continue?" checks. Datadog told OpenAI it uses it to score the risk of agent-generated shell commands before running them.
  • PentAGI from VXControl is a self-hosted, MIT-licensed multi-agent pentesting system: describe a target and goal, and its agents plan the work, run 20+ tools such as nmap, Metasploit and sqlmap in an isolated Docker sandbox and write a report. Unlike Strix and Shannon, which focus on your app's code, PentAGI works more like a full network pentest and can run on local models through Ollama or vLLM. About 32,000 GitHub stars; v2.2.0 shipped Oct 5. Authorized targets only.
