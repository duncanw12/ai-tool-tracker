Open Code Review (Alibaba)Free, open-source (Apache-2.0) AI code review command-line tool that started as Alibaba Group's internal code review assistant, which Alibaba says served tens of thousands of its developers over two years before it was opened up. Run ocr review in a repository and it reads your Git diff, groups related files, matches review rules to each file and has an agent read full files and search the codebase before writing line-level comments; ocr scan reviews whole files with no diff, for an audit of existing code. The built-in multi-language rule set covers bugs such as null-pointer errors and thread safety as well as security issues such as cross-site scripting (XSS) and SQL injection, and you can add your own rules by path. Two ways to run it: native mode uses any OpenAI- or Anthropic-compatible model endpoint you configure, and delegation mode lets the coding agent you already use (Claude Code, Codex, Cursor, Kimi Code or OpenCode) do the review under Open Code Review's file selection, rules and coverage checks, with no separate API key. Also runs in CI (GitHub Actions, GitLab CI, Gerrit), has a browser session viewer to mark findings fixed or ignored, and works on Windows, macOS and Linux (needs Git 2.41 or newer; install with npm install -g @alibaba-group/open-code-review). Alibaba's own benchmark (AACR-Bench, 200 real pull requests) reports higher precision than Claude Code on the same model at about a ninth of the tokens, with lower recall by design; those numbers are self-reported. About 53,400 GitHub stars (public since May 2026), about 181,700 npm downloads in the week of Nov 10-16, 2026, and frequent releases (v1.13.11 on Nov 17). An AI review is a second pair of eyes, not a replacement for a security scanner or a human reviewer.

Why this one

  • Open Code Review is the AI code reviewer with the most real-world use behind it that you can run for free. It started as Alibaba's internal review assistant, and since going public in May it has passed about 53,000 GitHub stars and about 180,000 npm downloads a week. Instead of asking a general agent to "review this", it decides which changed files must be reviewed, bundles related ones, matches review rules to each file, then lets an agent read the full code before it writes comments pinned to exact lines. The built-in rules include security checks such as cross-site scripting and SQL injection, and ocr scan reviews a whole folder with no diff, which is handy for auditing home-lab scripts or an old project. If you have no API key, delegation mode lets Claude Code, Codex, Cursor, Kimi Code or OpenCode do the review under its rules. It also runs in GitHub Actions and GitLab CI. Alibaba's own benchmark claims better precision than Claude Code at about a ninth of the tokens, with lower recall on purpose, so expect fewer false alarms but not every bug. Treat it as a second reviewer next to Semgrep or Snyk, not a replacement.

Listing updates

Checked on Nov 17, 2026 against official pages and release notes.

  • Claude Code: v2.1.326 (Nov 16) warns at startup when an --allowedTools, --disallowedTools or --tools entry does not look like a complete rule, warns and names the file when a permission rule you add cannot actually be saved, and stops describing Bash commands that delete or overwrite files (find -delete, cat a > b, sort -o) as a search or a read in the transcript. Code Mode now works with agent teams.
  • Qwen Code: v0.28.0 (Nov 17) runs headless sessions, the terminal UI and subagents on one shared agent loop by default, keeps the latest complete operation when a long session is compacted, shows per-turn hook statistics in the web shell and adds a DingTalk adapter. About 30,700 GitHub stars.
  • CISO Assistant: v4.3.3 (Nov 16) lets workflows fill in field defaults through inline event triggers and name the requester of a validation flow, keeps deprecated and draft items out of the landing-page briefing and fixes visual glitches in the library editor and metric charts.
