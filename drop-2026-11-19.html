SuperpowersFree, open-source (MIT) skills framework and development method for coding agents, built by Jesse Vincent and Prime Radiant. Instead of jumping straight into code, the agent first asks what you are really trying to build, shows the design back in short chunks for you to approve, writes a step-by-step plan with exact file paths and checks, then works through it with a fresh subagent per task and a review after each one. Skills trigger automatically and cover brainstorming, git worktrees, plan writing and execution, test-driven development (red, green, refactor), systematic debugging, verification before calling something done, requesting and receiving code review, finishing a branch, writing your own skills and diagnosing a session that went wrong. Installs from the official Claude Code plugin marketplace (/plugin install superpowers@claude-plugins-official) and the Codex plugin marketplace, and also works in Cursor, Gemini CLI, GitHub Copilot CLI, Google Antigravity, OpenCode, Factory Droid, Devin CLI, Qwen Code, Kimi Code, Grok Build CLI, Hermes Agent and more. The optional visual companion loads a logo that reports the Superpowers version in use; set SUPERPOWERS_DISABLE_TELEMETRY to turn it off. About 321,000 GitHub stars; v7.0.2 released Nov 3, 2026, and still near the top of GitHub Trending on Nov 19, 2026.

Why this one

  • Superpowers was the top repository on GitHub Trending this morning (about 2,000 stars in a day, about 321,000 in total). Built by Jesse Vincent and Prime Radiant, it is a set of skills plus a working method for coding agents: before writing code the agent asks what you are really building, shows the design back in short chunks, writes a plan of small tasks with exact file paths and checks, then works through it with a fresh subagent per task and a review after each. Test-driven development, systematic debugging and a verify-before-done step are built in, and the skills trigger on their own. It is in the official Claude Code and Codex plugin marketplaces and installs in Cursor, Gemini CLI, GitHub Copilot CLI, Antigravity, OpenCode and more. If you are learning to code with an agent, this is the closest thing to having it work the way a careful senior engineer would, and the plans it writes are worth reading on their own.

It is rolling out to Google AI Pro and Ultra subscribers in the Gemini app model menu, in Gemini for business, in Google Antigravity for paid Pro and Ultra subscribers and in the paid Gemini API at $3 per million input tokens ($0.15 cached) and $15 per million output tokens, with a 1 million-token context window.
