HOL Guard

Free, local-first guard for the AI coding agents you already use. It checks shell commands, file access, package installs and MCP tool calls before they run, flags secret exposure, destructive commands, prompt injection and supply-chain risk, and allows, blocks or asks you to approve each action based on your policy. Works with Claude Code, Codex, Cursor, GitHub Copilot CLI, Gemini CLI, Cline, OpenCode and others through their hooks, so coverage depends on what each agent exposes. Runs without an account, keeps a local history of every decision, can produce an AI bill of materials and SARIF output for CI, and has an optional Guard Cloud for team policies. Install with pipx (Python 3.10+). About 1,000 GitHub stars and roughly 76,000 PyPI downloads in the past month; v3.58.0 shipped Oct 27, 2026.
