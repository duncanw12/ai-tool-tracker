Why these two

  • 0 is a free, open-source (MIT or Apache-2.0) security harness from 0sec Labs, a Swiss team backed by Y Combinator. It is not a model: you connect your own model provider, then run code review, pentest, vulnerability research, verification and fix workflows from a local web console with a findings queue and board, from a headless CLI that writes SARIF and other reports, or as an MCP server so Claude Code or Codex can call the same workflows. Binary analysis goes through Ghidra with its 0verse add-on. About 1,190 GitHub stars; the repo dates from August, the public open-source launch was Nov 8 and it ships several releases a day (v0.28.9 on Nov 9). Its README is clear that the default shell runs on your host, so use an isolated executor for untrusted work, and only point it at systems you are authorized to test. A hosted 0cloud for PR reviews starts with $100 in trial credits, then $5 per PR test. It sits next to Strix, Shannon and Codex Security.
  • Neoverse answers the question before you install: is this MCP server, agent skill or extension safe to run? Neo, an AI security company, made its catalog free to search on Nov 9 with an email sign-in. Neo says it covers more than 4 million items from IDE marketplaces, browser stores, GitHub, the MCP registry and package managers, and marks each analyzed one Malicious, Unsafe or Safe with the key finding, a summary and version history. The verdicts come from Neo's own automated static, sandbox and documentation analysis, so treat them as one signal, not a guarantee, and Neo itself says signing up does not protect your machine. It pairs with SkillSpector and Snyk Agent Scan, which scan what you already have.

Listing updates

Checked on Nov 10, 2026 against official pages and release notes.

  • Claude: Claude Fable 5.2 (Nov 9) is Anthropic's model for the hardest reasoning and long-running agent work, on Pro, Max, Ultra, Team and Enterprise plans and in the API as claude-fable-5-2 at $8 per million input and $40 per million output tokens (down from $10 and $50 for Fable 5.1), with a 1M-token context. Anthropic still suggests starting most coding work on Claude Opus 5.5. Claude Mythos 5.2 is the same underlying model; Fable carries strong cybersecurity and biology safeguards so it can be offered to everyone, while Mythos is limited to organizations verified through programs such as Anthropic's Cyber Verification Program.
  • Claude Code: v2.1.321 (Nov 9) makes Fable 5.2 the default Fable model and fixes several security issues, including MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them, a read-only Bash command that could run outside the sandbox without a prompt, and deny rules not applying to files written by cp or mv into a directory. v2.1.322 adds fast mode on Vertex. Worth updating.
  • Ollama: v0.40.16 (Nov 9) adds Ripple Preview, a 65B dense model for agentic coding (ollama run ripple-preview), and makes ollama launch claude always route Claude Code to the model you picked.
