Why these two

  • Strix is a team of AI pentesting agents that runs your app in a Docker sandbox, hunts for issues like injection, broken access control, SSRF and XSS, and keeps only the findings it can confirm with a working proof of concept, along with suggested fixes. It has about 71,000 GitHub stars, v1.7.0 shipped Oct 5, and the open-source version is free with your own LLM key. Strix Cloud Pro is $29 a seat per month, with pentests billed separately. It can also run on every pull request in CI.
  • Shannon from Keygraph is a whitebox AI pentester: it reads your source code to find likely attack paths, then executes real exploits against the running web app and APIs. Its rule is "no exploit, no report." About 49,000 GitHub stars; v3.4.0 shipped Oct 6. Shannon itself is free (AGPL-3.0) and you pay only your own model costs; Keygraph Pro, the hosted platform, is $50 per developer per month. Anthropic and OpenAI apply cyber-security safeguards that can interrupt a scan, so Shannon's README asks you to clear your provider's cyber verification first.
  • For students: both are a good way to see how real web attacks work. Point them only at a deliberately vulnerable practice app in your own lab, or at something you have written permission to test, and never at production.

Listing updates

Checked on Oct 22, 2026 against official pages and announcements.

  • Devin: devin.ai/pricing is back online and confirms the lineup we listed from the billing docs: Free, Pro $20 a month, Max $200 a month, and Teams at $80 a month plus $40 per full seat. Pro now includes free use of Cognition's own SWE-2 model.
  • OpenCode 2.0: Anomaly announced it Oct 12. One background service now powers the terminal, web and desktop apps, with a rebuilt API and background subagents. It ships as a separate package (@opencode/cli, at 2.1.2 this morning); the default install still gives you 1.x (1.19.3), and V1 plugins don't carry over, so check yours before running opencode upgrade --major.

Category changes

  • AI for IT & Cybersecurity grows from 28 to 30 tools. The Breaking into IT guide adds Strix and Shannon to the vulnerability scanning step, for practice apps in an isolated lab only.

Checked, not listed

  • Buddy: an Apache-2.0 Android app that lets Claude Code, Codex or OpenCode tap through your phone's apps and asks before anything that sends, posts, buys or deletes. Clever approval design, but it's two weeks old with about 100 GitHub stars, so we'll watch it.
  • Hermo (turns a logged-in ChatGPT tab into an API) and freavy (a local ComfyUI canvas): both are brand new with only a handful of GitHub stars. Driving a ChatGPT tab as an API may also run against OpenAI's terms, so check before you rely on it.
  • MiniMax M3.1 Flash: still API-only. The open weights reported for Oct 23 weren't on MiniMax's Hugging Face page this morning.
