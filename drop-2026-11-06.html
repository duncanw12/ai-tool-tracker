Why these two

  • CVE Intel answers the question every IT and security team asks about a CVE: does it affect us, and do we patch now? Give it a CVE ID, a project folder or lockfile, an SBOM, a container image or the software installed on your own computer, and it checks up to 41 public sources (NVD, CISA KEV, FIRST EPSS, ENISA EUVD, OSV, GitHub Advisories and more, many without an API key) and returns a 0-100 risk score, whether the bug is already exploited, the evidence and a next step. It is one Rust executable that is a desktop app, CLI, REST API and a 41-tool MCP server, with an optional Ask AI assistant on a small local model. Free under MIT or Apache-2.0, installers for Windows, macOS and Linux (not code-signed yet), about 135 GitHub stars and frequent releases (v0.3.27 on Nov 2). It is a hands-on way to learn vulnerability management, a core skill for SOC and sysadmin roles.
  • Grim Prompter comes from Jim Manico, a well-known application security trainer and OWASP contributor. It is a skill for Claude Code, Codex or any agent that reads AGENTS.md: ask for /threat-model and the agent inspects your repo read-only, maps trust boundaries, threats and existing controls, and writes a report with file-and-line citations plus JSON you can diff when the code changes. 36 architecture workflows (web, API, MCP servers and more) and 29 method prompts such as STRIDE per element. Free under MIT; about 375 GitHub stars about a week after its Oct 28 release. Treat the output as a draft to challenge, not a certification. We already list scanners like Semgrep and Codex Security that find bugs; Grim Prompter is the design-level review that comes before them.

Listing updates

Checked on Nov 6, 2026 against official pages and release notes.

  • AiSOC: v22.2.0 (GitHub release Nov 5, 9:43 PM ET) follows two security releases with reliability work. A fusion worker that lost its message broker (for example at a cold boot) used to stay down until someone restarted the container; it now retries with backoff and readiness recovers on its own. A new CI check requires every connector to read its full poll window, after six connectors shipped a paging bug that could miss alerts; the project lists about 20 more connectors it could not yet confirm against vendor docs. If you run AiSOC, updating is worthwhile, and the v22.1.0 advice still stands: set your own SECRET_KEY.
