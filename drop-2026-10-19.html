Security note: OpenCode Console keys

On Oct 17, OpenCode said someone got into a legacy system behind its hosted Console and may have exposed the OpenAI, Anthropic and Google API keys saved in Console workspaces. It put the share of Console users affected at 1.4% and emailed all of them. The co-founder says keys added locally in the OpenCode CLI or desktop app never reach its servers, so they weren't part of it. If you got the email: revoke and replace those keys in each provider's dashboard, check your provider usage back to Oct 16, and set a spend limit. We've added the note to the OpenCode listing.

Why these five

  • Security Onion is a free, open platform for network security monitoring, threat hunting and log management with more than 2 million downloads. It's one of the first things people stand up in a SOC home lab. Its Onion AI assistant (alert analysis, detection tuning, now with local models) comes with the paid Pro edition.
  • Nuclei from ProjectDiscovery has about 32,000 GitHub stars. Its -ai option turns a plain-English prompt into a scan template. Only scan systems you own or have permission to test.
  • promptfoo is the open-source way to test and red-team LLM apps (about 26,000 GitHub stars). The free Community edition includes red teaming up to 10,000 probes a month.
  • Freshservice is a cloud IT service desk that shows up in a lot of help desk job posts. Starter is $19 per agent a month billed annually, and there's a free trial to practice working tickets.
  • InvokeAI is a free, Apache-2.0 image studio you run on your own GPU, with a canvas, node workflows and support for FLUX.2, SD 3.5 and Qwen Image. v7.0 is in alpha.

Pricing checked today
