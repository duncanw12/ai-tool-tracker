Why these two

  • Foundry Local is Microsoft's answer to "how do I ship local AI inside my app without standing up a server?" You install a thin SDK (~20 MB runtime), pick a catalog model (Phi, Qwen, DeepSeek, Mistral, Whisper and others), and inference stays on the user's device with automatic NPU/GPU/CPU acceleration and OpenAI-compatible APIs. No Azure subscription, no API key, no per-token cloud bill. Generally available since April 2026; GitHub Copilot CLI's voice input, Raycast and Foxit already use it. The SDK is MIT; about 2,640 GitHub stars; v2.3.1 on Nov 2. It sits next to Ollama: Ollama is how you run models yourself, Foundry Local is how you embed them in software you ship.
  • FlutterFlow launched an AI-native experience on Nov 4, 2026 for native iOS and Android (backend, auth, analytics and store deploy included). You describe the app, the agent builds in its own thread copy, and nothing reaches your live app until you push. The visual builder continues as FlutterFlow Studio. FlutterFlow reports 3.3M builders and 50,000+ apps shipped, so this is a real alternative to web-only vibe builders like Lovable and Bolt when the target is mobile.

Listing updates

Checked on Nov 7, 2026 against official pages and release notes.

  • CVE Intel: v0.3.28 (GitHub release Nov 6, 11:28 PM ET / Nov 7 UTC) adds OAuth 2.1 and HTTPS for cve-intel serve. Serving on a non-loopback address, including Docker's 0.0.0.0, now requires OAuth or the explicit opt-out CVE_INTEL_ALLOW_UNAUTHENTICATED=1. The desktop app and serve on 127.0.0.1 are unchanged. About 137 GitHub stars.
  • Cursor: Build Live Apps (changelog Nov 5, 2026). On paid plans with cloud agents, a cloud agent can scaffold a web app, provision Postgres, put team apps behind Cursor SSO, run security checks and publish a live URL. Deploy from Cursor Origin or GitHub; admins can review and unpublish. Hosting price is not listed in the docs.
  • SkillSpector: v2.13.4 (Nov 4) maintenance release for provider compatibility and source inspection; GitHub stars now about 24,700 (was ~21,000 when last listed).
