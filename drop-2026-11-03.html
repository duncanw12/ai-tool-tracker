Why these two

  • Deckard answers a question security teams now get asked a lot: which AI agents are actually running here? Arthur released it today as free, MIT-licensed software. It scans endpoints with osquery (using Arthur's open ai-detection-spec catalog), cloud AI platforms like Vertex AI Agent Engine and AWS Bedrock, cloud network logs and your existing Splunk or Elastic data, then sends one event per agent it finds to your SIEM or a webhook. It's read-only and runs in your own environment. The quickstart scans your own machine with Docker Compose and osquery and shows the findings in a local Kibana, which makes it a good home-lab exercise in endpoint visibility. It's brand new (about 170 GitHub stars on launch day), so expect rough edges.
  • Failproof AI sits between your coding agents and your machine. It hooks 12 agent harnesses, including Claude Code, Codex, GitHub Copilot CLI, Cursor Agent, OpenCode and Factory Droid, records every run, and blocks dangerous tool calls before they execute using 40 built-in policies or your own TypeScript rules. A local dashboard needs no account, and failproofai audit looks back over your history for risky patterns. It has about 7,600 GitHub stars, and v1.0.13 (Nov 2) fixed cases where policies had silently stopped applying on newer OpenClaw and Antigravity versions, a reminder to update guardrail tools as often as the agents they guard. We already list HOL Guard for a similar job; Failproof AI covers more harnesses and adds run history. Its license is MIT with the Commons Clause: free for personal and internal use, but not for reselling.

Listing updates

Checked on Nov 3, 2026 against official pages and release notes.

  • Google Security Operations: Agentic Chat is now in public preview (Google SecOps weekly update, Nov 2). It's a rebuilt multi-turn chat for investigating incidents, built on ADK 2.0 with MCP access to SecOps inside the platform. Also in preview: a faster Basic mode for SIEM search, and the MITRE ATT&CK dashboard now supports ATT&CK v19.1. Preview features fall under Google's Pre-GA terms.
  • HackAgent: v0.17.0 (Nov 2) lets campaigns queued from the dashboard run on a cloud worker, each run in its own process, with an allowlist of what a campaign may send to the cloud, or locally with hackagent run. It also adds two attacks: ToolHijacker tool-document poisoning and execution-verified STAC tool chains.
