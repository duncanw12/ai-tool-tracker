Why these two

  • AiSOC is a free, MIT-licensed AI security operations center you run on your own server. It pulls in telemetry from your security tools (87 connectors, including Splunk, Sentinel, Elastic, CrowdStrike, Okta and AWS), runs detection rules, groups alerts into incidents and has an AI agent triage each one. Every prompt, tool call and citation goes into a replayable Investigation Ledger, so you can check how the AI reached a verdict instead of trusting a summary, and a human approves any action before it reaches a vendor. It ships a small local model (Llama 3.2 3B through Ollama) that runs on CPU with no API key, plus an MCP server for Claude, Cursor and Continue. It has about 5,800 GitHub stars and shipped v21.0.0 today. One caution: the bundled model is small, so treat its verdicts as a first pass; the project itself publishes an audit of what works and what doesn't yet.
  • RedAmon is an open-source (MIT), self-hosted AI penetration testing framework. It runs recon tools in parallel, builds a graph of your attack surface, lets an AI agent attempt exploits from a Kali sandbox with human approval gates and can open GitHub pull requests that fix what it found. It speaks MCP both ways, so you can drive it from Claude Code. The project says it solved 101 of 104 XBOW web-security benchmark challenges black-box; that is its own claim. About 3,300 GitHub stars. It needs a fairly big machine (about 7 GB RAM and 80 GB disk without OpenVAS) and is for systems you own or have written permission to test only.

Listing updates

Checked on Nov 1, 2026 against official pages and announcements.

  • Claude Code: v2.1.314 (Oct 30) adds permissions.blockWritesOutsideWorkingDirectories. Turn it on and Write, Edit and NotebookEdit refuse any path outside your working directories, in every permission mode, which is a simple guardrail if you let the agent run with fewer prompts. v2.1.316 (Oct 31) adds CLAUDE_CODE_DISABLE_ULTRATHINK and CLAUDE_CODE_SUBAGENT_EFFORT.
  • Perplexity: on Oct 30 Perplexity said a new Chrome extension lets Computer in its Mac and Windows apps work inside the Chrome you already use, so it can use sites you're signed into. The extension listing says Edge, Brave, Arc and other Chromium browsers work too, and that Computer uses the browser only during a task you start. Comet doesn't need it.

Category changes

  • AI for IT & Cybersecurity grows from 45 to 47 tools. The Breaking into IT guide adds AiSOC (run it in your home lab with sample data and review each AI triage verdict like a Tier 1 analyst) and RedAmon (point it only at a deliberately vulnerable practice app in an isolated lab).

Checked, not listed

  • Vigil SOC 1.0 (Oct 30): another open-source AI SOC that hit general availability, with about 400 GitHub stars. Worth watching, but AiSOC has far more users today.
  • Pipelock: an open-source agent firewall that scans an agent's HTTP and MCP traffic for leaked secrets and prompt injection (about 950 stars). Solid, but it overlaps HOL Guard and Project Quarry, which we already list.
  • Mitigant MCP server (Oct 31): lets agents run Mitigant's cloud attack emulation, but it is for existing Mitigant customers.
