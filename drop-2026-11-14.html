Vigilo (CERT-EU)Open-source AI penetration-testing and code-review harness built by CERT-EU, the cybersecurity service for the EU institutions, and open-sourced on Nov 13, 2026. Point it at a web application you own: specialised agents, one per vulnerability class (injection, XSS, authentication, SSRF, authorization, GraphQL, WebSocket, cryptography and supply chain), map the target, share findings through a common knowledge base and try to exploit them with captured evidence, then an adversarial critic re-checks every finding, challenges its severity and merges duplicates before it reaches the report. White-box mode reads the source (plus an optional running instance) and proposes a fix branch per confirmed finding; grey-box mode tests only the running app with valid credentials and adds detection hints for the blue team. Runs as a multi-user web platform (Docker Compose, optional GitLab integration) or a command-line pipeline, and drives an agentic coding CLI (Claude Code, OpenAI Codex or OpenCode) with cloud or on-premises models, so you supply the model access. CERT-EU says findings and patches must be validated by the code owners, and it was part of an ENISA proof of concept on AI source-code testing. Why these two

  • Vigilo is the harness CERT-EU, the cybersecurity service for the EU institutions, built to point AI agents at code from a security angle, and it open-sourced it on Nov 13. Instead of one agent, it runs specialised agents per vulnerability class (injection, XSS, authentication, SSRF, authorization, GraphQL, WebSocket, cryptography and supply chain) that share a knowledge base and try to prove each finding with evidence. Then an adversarial critic re-checks every finding, pushes back on inflated severities and merges duplicates, so the report is not a pile of maybes. With source code (white-box) it proposes a fix branch per confirmed finding; without it (grey-box) it tests the running app with valid credentials and adds detection hints for defenders. It drives Claude Code, Codex or OpenCode with cloud or on-premises models, so you bring the model access. It is brand new on GitHub with very few stars, so treat it as a serious reference design from a real CERT rather than a proven community tool, and only run it against apps you own, such as an intentionally vulnerable app in your home lab. CERT-EU itself says findings and patches must be checked by the code owners.
  • Qwen Code is one of the most used open-source coding agents (about 30,100 GitHub stars) and we had not listed it. It works with OpenAI, Anthropic, Gemini and Qwen APIs or a local model in Ollama or vLLM, which makes it a good no-lock-in option next to Claude Code and Codex. The 1.0 Preview (Nov 11) merges in the agent harness from Alibaba's Qoder and ships native installers for macOS, Linux and Windows; it is a preview, so settings may change. The stable v0.27.3 shipped Nov 13.

Listing updates

Checked on Nov 14, 2026 against official pages and release notes.

  • Claude Code: v2.1.325 (Nov 13) fixes a security issue in how zstd-compressed responses are decoded. It also tells you how to continue (run /rewind and change the message, or /clear) when your organization's policy blocks a request, and fixes /security-review stopping with an error in worktrees of bare repositories and --separate-git-dir checkouts. Update if you are on v2.1.323 or older.
  • OpenAI Codex: CLI 0.169.0 (Nov 13) keeps project configuration and MCP servers disabled for codex exec in untrusted directories, even with --sandbox workspace-write; pass --trust to codex exec or codex review to save project trust on purpose. You can now add or edit custom model providers from the terminal, the opt-in terminal workspace gets multiple side-chat tabs, and Windows sandbox handling for quoted cmd.exe paths is fixed.
  • CISO Assistant: v4.3.0 (Nov 13) adds service accounts federated with an external OIDC identity provider, an MCP tool for reviewing evidence, a more actionable landing-page briefing, a Hungarian NIS2 compliance preset and requirement names for the NIS2 2024/2690 framework, and tightens bulk-action permissions.
