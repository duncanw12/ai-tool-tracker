Why these three

  • Snyk Agent Scan answers a different question from yesterday's SkillSpector: not "is this skill safe to install?" but "what have my agents already got?" It looks through the config folders of Claude Code, Claude Desktop, Cursor, VS Code, GitHub Copilot, Windsurf, Gemini CLI, Codex, OpenCode and others, lists every MCP server and skill it finds and scores them for prompt injection, tool poisoning, private-data exposure, destructive capabilities, malicious code and secrets. Two things to know: scanning an MCP config can start that server or contact its URL, so it asks first and Snyk suggests a sandbox for untrusted configs; and it needs a free Snyk API token because the analysis runs on Snyk's Agent Scan API (secrets are redacted before sending). Apache-2.0, about 3,200 GitHub stars, v0.6.9 shipped Oct 20.
  • Cisco Skill Scanner from Cisco AI Defense is the one to wire into a pipeline: SARIF output for GitHub Code Scanning, a reusable GitHub Actions workflow, a pre-commit hook and exit codes that fail a build. It layers YAML and YARA-X rules, code and dataflow analysis and an optional LLM judge (cloud or local models). What stands out is honesty: Cisco publishes measured results on a held-out test set, where rules alone caught 7.7% of malicious skills at HIGH, and with the LLM judge 66.7% reached review at MEDIUM or above at a 15.4% false-positive rate. In other words, a clean scan is not a clean bill of health. Apache-2.0 (the LICENSE file says so, even though GitHub doesn't detect it), about 2,600 stars, 2.3.1 shipped Oct 21.
  • Off Grid AI is a free, open-source assistant that keeps everything on your own device: chat with local models, ask about photos, transcribe speech, generate images, chat with your documents and use tools or MCP servers, with no account and no cloud inference. It runs on iPhone, Android and Mac, and the desktop app (macOS, Windows, Linux) also exposes a local OpenAI-compatible API other apps can use. The developer launched it on Reddit on Oct 24 and reports 250,000+ downloads; the mobile repo has about 3,300 GitHub stars and shipped v0.0.118 on Oct 23. Pro is optional: $119 lifetime or $7.99 a month per the README (the Pro page currently shows a $79.99 launch price), and adds voice replies, on-device memory, phone-to-Mac sync and approval-gated actions.

Listing updates

Checked on Oct 25, 2026 against official pages and announcements.

  • NVIDIA Nemotron 3.5 Bolt: NVIDIA released Nemotron 3.5 Bolt E4B on Oct 23, a small model (8B total, 4B effective, built on Gemma 4 E4B) for fast local voice and device assistants, with multi-turn tool use, a conversational mode for short speech-ready replies and switchable reasoning. NVIDIA's 4GB Q4_K_M GGUF used 3.5-4.3GB of VRAM on an RTX 5070 in its own tests, and it's in Ollama as nemotron-3.5-bolt:e4b (a 7.2-7.9GB download that includes image input; MLX builds for Apple silicon too). OpenMDW-1.1 license, commercial use allowed.
  • ElevenLabs: Eleven Realtime Translation (Oct 21) translates live speech into speech in 90+ languages in a voice you pick or clone, with automatic language detection and a setting that trades speed for quality. It's an alpha for ElevenAPI enterprise customers only (contact sales); there is no public price yet.
  • HeyGen: the HeyGen Voice Turbo Free API model (heygen-voice-1-turbo-free) is free until Nov 30, 2026, with no credit balance needed. It works with public voices and instant clones (not professional clones), shares limited capacity (expect occasional HTTP 429s) and HeyGen pitches it for tests and prototypes.
