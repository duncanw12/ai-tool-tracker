Why these two

  • Frontier UI is the missing visual layer for people who already run local models in Open WebUI. Instead of a wall of Markdown, the model returns a small JSON spec and Frontier renders interactive cards: real photo galleries (Wikipedia/Commons/Openverse, no keys by default), live street maps with walking or driving routes, multi-day itineraries, budget sliders, weather and stock charts, link previews and optional real Word/Excel/PowerPoint/PDF exports through ArtCraft. Install is one Python file pasted into Workspace → Tools; enable it for a tool-calling model. MIT licensed, v1.3.2 (Nov 3), about 60 GitHub stars four days after launch. Default setup still calls free public map/photo/weather services, so it is not fully offline unless you add the optional self-hosted planet map. We list Ollama and LM Studio for running models; Frontier is what makes those answers feel useful in the chat UI.
  • Codex Security is OpenAI's answer to "have an agent actually review my code for vulns." Use the Codex plugin, the @openai/codex-security CLI (cs scan .) or the TypeScript SDK to scan a repo, paths or a git diff, validate findings, generate patches and export SARIF for CI. It can also import Semgrep, Snyk or Wiz results. About 11,300 GitHub stars under Apache-2.0; npm 0.8.3 as of Nov 3. OpenAI inference needs Codex Security / API access on your account (usage billed there); Bedrock and some other providers are supported. Some cyber requests need Trusted Access for Cyber. Only scan code you own or are allowed to review. We already list Semgrep, Snyk and Copilot Autofix; Codex Security is the OpenAI-native agentic scanner that sits next to them.

Listing updates

Checked on Nov 5, 2026 against official pages and release notes.

  • AiSOC: v22.1.0 (Nov 5) continues yesterday's security work. Highlights: a critical advisory where the documented one-click demo deploy signed session tokens with the default SECRET_KEY published in the repo (anyone who could read the repo could mint any role on those demos); high-severity bypasses of the connector egress guard, including hostnames that were not shaped like full URLs; password resets that left existing sessions alive and a TOTP code that could open more than one session; plus medium issues for committed .env backups still in git history and agent tool arguments that skipped schema checks. If you run AiSOC, update and set your own SECRET_KEY on any deployed instance.
  • AI-Infra-Guard: v4.6.9 (Nov 5) adds a CloudGPU provider preset for agent scans, puts timeouts on task-server HTTP clients and fixes MCP-scan handling of XML-attribute parameter tags and mixed-case SARIF rule IDs. Still free under Apache-2.0; keep it on a lab network (no login).
