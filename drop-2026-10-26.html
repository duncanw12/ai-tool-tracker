Strands BoxOpen-source sandbox for AI agents from the Strands Agents project. It runs any agent program inside OS-level isolation and checks its shell commands, Python, network requests and MCP tool calls against default-deny policies (written in the Dogwood policy language), so an agent can only do what a rule permits. Why these three

  • Strands Box is the next step after this week's scanners. SkillSpector, Snyk Agent Scan and Cisco Skill Scanner tell you whether a skill or MCP server looks risky; Box limits what an agent can do even if something bad gets through. It runs the agent inside OS-level isolation and sends its shell commands, Python code, network requests and MCP tool calls through one default-deny policy engine (rules written in Dogwood), so nothing runs unless a rule permits it. Rules can look at history: a file read can block a later outbound request, which is exactly the "read the secrets, then send them somewhere" pattern you worry about. API keys stay in Box's gateway, not in the agent, and every allow or deny is logged. Caveats: it's a preview that runs on Apple silicon Macs only (Linux is planned), v0.1.0 shipped Oct 7 and it has about 475 GitHub stars. Apache-2.0.
  • Nanbeige4.3-33B is the open model people were talking about this weekend: a 33B dense model released Oct 24 under Apache-2.0, with a 512K-token context and a thinking mode you can turn off. Nanbeige's own table has it ahead of Qwen3.8-27B, Muse-Glimmer-30B and Gemma4-31B on most agent benchmarks (80.9 on Terminal-Bench 2.1, 65.5 on DeepSWE), but Qwen3.8-27B still wins SWE-Bench Pro (61.7 vs 60.3) and GDPval. These are the vendor's numbers, so test it on your own tasks. Full weights are server-sized (the SGLang and vLLM examples use four GPUs); community GGUF quants have already appeared on Hugging Face.
  • Cloudflare Clairic fixes a boring, common job: pulling the total, date or order ID out of an invoice or email. You declare typed fields and it returns a value of that type (or null) with a confidence score, in one pass with no generated tokens, so there's no malformed JSON to clean up. It costs $0.10 per million input tokens with no output charge. It's a preview: Cloudflare says longer chains of arithmetic don't work well yet, and every input goes to Cloudflare until the promised open weights arrive. It sits next to the OpenAI Decisions API: Decisions picks among answers, Clairic extracts values.
