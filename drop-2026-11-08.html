StroqFree, open-source (Apache-2.0) local security CLI for AI coding agents. Run npx @stroq/cli and it reads your last 30 days of Claude Code and Codex sessions and shows how many commands came from text the agent read and which keys left your machine; stroq sent checks Claude Code, Codex CLI and Cursor sessions against the credential files on your computer and reports where each key went, printing key names, never values. stroq init installs hooks (Claude Code, Cursor, Codex, Copilot CLI, Windsurf, Antigravity, plus an MCP proxy) that deny curl-pipe-to-shell and outbound calls carrying a known secret, and ask you first when a command repeats text the agent read. A local console on 127.0.0.1 shows every decision with its reason. No account, no telemetry; needs Node.js 22+. Matching is text-level, so it is a filter, not a sandbox. About 210 GitHub stars and about 600 npm downloads in the week of Nov 1-7, 2026; v0.30.0 shipped Nov 5 alongside a Show HN post.

OrcaFree, open-source (MIT) desktop app from Stably AI (Y Combinator) for running several coding agents in parallel, each in its own git worktree. Bring the CLI agents and subscriptions you already have (Claude Code, Codex, Gemini, GitHub Copilot, OpenCode, Cline, Grok and any other terminal agent), use each in a chat view or the raw terminal, and review diffs, leave line notes and send PR review comments or failing checks back to an agent. A coordinator agent can split a big task across worker agents; workspaces can run locally, on an SSH host or a cloud VM, and an iOS and Android companion app pings you when an agent needs input. Prompts go straight to the providers you configure. Builds for macOS, Windows and Linux. About 119,000 GitHub stars; ships almost daily (v1.4.252 on Nov 6, 2026 added chat forking and Plan mode).

Why these two

  • Stroq answers a question most guardrail tools skip: what did my agent already do? Run npx @stroq/cli and it reads your last 30 days of Claude Code and Codex sessions; stroq sent compares Claude Code, Codex CLI and Cursor sessions with the credential files on your machine and says where each key went, printing names, never values. stroq init then adds hooks that deny curl | sh and outbound calls carrying a known secret. Free (Apache-2.0), local, no account or telemetry. About 210 GitHub stars, about 600 npm downloads last week and a Show HN on Nov 5 with v0.30.0. Its own README is clear about limits: text-level matching, a filter rather than a sandbox. It pairs with HOL Guard and Failproof AI on the guard side, and with Strands Box when you want a real sandbox.
  • Orca is a free, MIT-licensed desktop app from Stably AI with about 119,000 GitHub stars. It does not ship its own model: you plug in the agent CLIs and subscriptions you already pay for (Claude Code, Codex, Gemini, Copilot, OpenCode, Cline and others) and run them side by side in separate worktrees, with diff review, line notes, a coordinator that splits work across worker agents, remote and cloud workspaces and a phone app that pings you when an agent needs input. It is free, ships almost daily, and is now on our Cursor alternatives page.
